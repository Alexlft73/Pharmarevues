# 📘 PharmaVeille

Veille scientifique pour pharmacien officinal : **revues de recherche clinique 2024–2026**, sourcées et vérifiées (PubMed / NCBI E-utilities), classées par **force de preuve** (N1 méta-analyse → N5 revue narrative), avec analyse des **conflits d'intérêts** et message « à dire au patient » pour chaque entrée.

## Consultation

- `index.html` — le site complet : 📚 Mes revues · 🔎 Recherche & conflits d'intérêts · 💊 Classes de médicaments
- `guide-filtres.html` — moteur de recherche à facettes (type site marchand, compteurs dynamiques)
- `classes-medicaments.html` — module classes de médicaments (fiche pro + version patient à schéma SVG)
- `fiches-medicaments.html` — fiches médicaments double lecture pro / patient
- `depliant-filtres.html` — dépliant A4 des filtres (à imprimer)

Tous les fichiers sont **autonomes** : ils s'ouvrent hors ligne par double-clic, sans installation ni dépendance.

## Mise à jour

La base est enrichie par veille planifiée (Mistral) : chaque entrée est vérifiée (PMID, date de publication, extrait lu, financement) avant d'être ajoutée. Aucune donnée patient n'est stockée ici.

⚠️ Usage professionnel de santé — les informations ne remplacent pas le RCP ni l'avis médical.
